# WonderBox 0.2.0

WonderBox 现在更像一款真正的菜单栏工具：关闭窗口后退出 Dock，只保留菜单栏面板。

WonderBox now behaves like a proper menu bar utility: close the window and it leaves the Dock, keeping only the menu bar panel.

## 新增功能 / What’s New

- **关闭窗口后隐藏 Dock 图标**：开启菜单栏快捷入口时，关闭主窗口后 WonderBox 仅驻留菜单栏，不留下闲置的 Dock 图标。通过 Finder、Spotlight 或菜单栏面板中的“打开主窗口”重新打开时，Dock 图标恢复。

  **Leaves the Dock when the window closes:** with the menu bar shortcut on, closing the main window makes WonderBox a menu-bar-only app with no idle Dock icon. Reopening it through Finder, Spotlight, or Open Main Window in the menu bar panel brings the Dock icon back.

- **关闭菜单栏入口时询问是否退出**：此时关闭窗口会失去返回入口，因此 WonderBox 会询问开启菜单栏入口还是立即退出。“不再询问”复选框以及 **设置 → 常驻 → 退出前询问** 控制该提示。

  **Quit prompt when the menu bar shortcut is off:** closing the window without a menu bar shortcut would leave no way back, so WonderBox asks whether to enable the shortcut or quit now. A Don’t ask again checkbox and the **Settings → Always Available → Ask before quitting** toggle control the prompt.

- **可靠显示启动窗口**：修复启动后只有 Dock 图标、必须点击图标才显示窗口的情况。

  **Reliable window at launch:** fixed a case where the app started with a Dock icon but no window until the icon was clicked.

仅保留一个主窗口：⌘N 不再创建重复窗口。

Single main window: ⌘N no longer opens a duplicate.

## 安装 / Installation

要求 **macOS 14 或更新版本**。ZIP 包含支持 **Apple Silicon 和 Intel** 的通用版 `WonderBox.app`。

Requires **macOS 14 or newer**. The ZIP contains a universal `WonderBox.app` for **Apple Silicon and Intel**.

安装包使用 **ad-hoc 临时签名，未公证**，首次启动会被 Gatekeeper 拦截。右键点击应用 → 打开，并在“系统设置 → 隐私与安全性”中确认，或执行以下命令：

The build is **ad-hoc signed and not notarized**, so Gatekeeper blocks the first launch. Right-click the app → Open and confirm in System Settings → Privacy & Security, or run:

```bash
xattr -dr com.apple.quarantine /Applications/WonderBox.app
```

风扇控制和内存优化会在首次使用时安装一个小型 root helper（需要一次管理员授权）。所有操作均在本机执行，不上传数据。

Fan control and memory optimization install a small root helper on first use (one administrator prompt). Everything runs locally; nothing is uploaded.
