# WonderBox 1.2.5

构建号：**125**。修复 Navicat Premium 和 DataGrip 的默认配置目录在卸载扫描中被遗漏的问题。

Build **125**. Fixes uninstall discovery missing the default configuration directories used by Navicat Premium and DataGrip.

## 卸载残留 / Uninstall leftovers

- Navicat Premium 的 `~/Library/Application Support/PremiumSoft CyberTech/Navicat CC/Navicat Premium` 产品目录现在会被发现；共用的 `PremiumSoft CyberTech`、`Navicat CC` 和其他 Navicat 产品目录不会被整目录选中。
- DataGrip 的 `~/Library/{Application Support,Caches,Logs}/JetBrains/DataGrip<版本>` 目录现在会被发现，旧版本也会显示；其他 JetBrains IDE、备份目录和项目目录会排除。
- 新发现的厂商目录默认为待确认，用户勾选后才会移入废纸篓。
- DataGrip 项目级连接仍保存在项目 `.idea/dataSources.xml` 中；重新打开原项目时连接仍会显示，这是项目数据而非应用配置目录。

- Navicat Premium's product directory under `~/Library/Application Support/PremiumSoft CyberTech/Navicat CC/Navicat Premium` is now discovered without selecting the shared vendor parents or other Navicat products.
- DataGrip directories under `~/Library/{Application Support,Caches,Logs}/JetBrains/DataGrip<version>` are now discovered, including older versions; other JetBrains IDEs, backups, and project directories are excluded.
- Newly discovered vendor folders require explicit review and selection before they are moved to the Trash.
- DataGrip project-level connections remain in the project's `.idea/dataSources.xml`; reopening the original project can still show them because they are project data rather than application configuration.
