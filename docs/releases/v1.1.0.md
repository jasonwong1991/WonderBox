# WonderBox 1.1.0

构建号：**110**。新增功耗监测，并修复普通 ZIP 被误识别为安装包的问题。

Build **110**. Adds power monitoring and fixes ordinary ZIP archives being misclassified as installers.

## 功耗监测 / Power Monitoring

- 新增独立的 **功耗** 页面，显示整机、CPU、GPU 当前功率，单位为瓦特（W）。可切换最近 **1 分钟／15 分钟／1 小时**曲线，并查看实际采样区间的平均值和峰值。

  A dedicated **Power** page shows current system, CPU and GPU watts, with **1-minute / 15-minute / 1-hour** charts and averages and peaks over observed intervals.

- Apple Silicon 优先读取 macOS IOReport 能量计数器，按实际采样间隔换算功率；整机功耗及受支持的 Intel／部件回退使用 SMC。界面显示数据源，CPU 封装读数可能包含集成 GPU，重叠读数不会累加为整机功耗。这些是硬件或系统模型读数，并非插座电表测量值。

  Apple Silicon prefers macOS IOReport energy counters divided by the actual sample interval. SMC provides system power and supported Intel/component fallbacks. Sources are labeled; CPU-package readings may include integrated graphics, and overlapping readings are not added into system power. These are hardware/model readings, not wall-outlet measurements.

- 风扇单独显示实际转速。独立风扇瓦数目前没有受支持的数据源，因此明确显示 **—**，不从 RPM 推算瓦数。其他缺失或过期读数也不会伪装成零。

  Actual fan RPM is shown separately. Independent fan watts have no supported source and explicitly show **—**; RPM is never converted into invented watts. Missing or stale readings are not represented as zero.

- 沿用实时监测生命周期，约每 3 秒采样，切换其他页面也会采集；最近一小时仅保存在内存。暂停、睡眠、传感器缺失和数据源变化处保留曲线断点，退出应用后清空历史。无需管理员权限，也不新增后台服务或遥测。

  Sampling follows the existing live-monitoring lifecycle, approximately every three seconds, including on other tabs. Up to one hour is kept in memory. Pause, sleep, missing sensors and source changes break chart segments; quitting clears history. No administrator access, new background service or telemetry is introduced.

## 安装包 ZIP 识别修复 / Installer ZIP Detection

普通项目或照片压缩包不再因为路径中的目录名以 `.app`、`.pkg`、`.mpkg` 或 `.dmg` 结尾就被归为安装包。例如，`project/service.app/src/main.swift` 和 `photos.dmg/holiday.jpg` 都应保留为普通文件。

Project and photo archives are no longer classified as installers merely because an ancestor directory ends in `.app`, `.pkg`, `.mpkg` or `.dmg`. For example, `project/service.app/src/main.swift` and `photos.dmg/holiday.jpg` remain ordinary files.

现在只识别实际安装包文件或包含标准 `Contents/Info.plist` 路径的应用／旧式安装包，并忽略 Finder 元数据。这补齐了 0.3.0 中 ZIP 内容检查遗漏的边界情况。

Detection now requires an installer file or the standard `Contents/Info.plist` path of an application/legacy package bundle, and ignores Finder metadata. This closes an edge case left by the ZIP-content check introduced in 0.3.0.

感谢 [@Mr-xiongyq](https://github.com/Mr-xiongyq) 提交 ZIP 修复（[#7](https://github.com/jasonwong1991/WonderBox/pull/7)），以及 [@ghr1025](https://github.com/ghr1025) 提出功耗监测建议（[#8](https://github.com/jasonwong1991/WonderBox/issues/8)，实现见 [#9](https://github.com/jasonwong1991/WonderBox/pull/9)）。

Thanks to [@Mr-xiongyq](https://github.com/Mr-xiongyq) for the ZIP fix ([#7](https://github.com/jasonwong1991/WonderBox/pull/7)) and [@ghr1025](https://github.com/ghr1025) for requesting power monitoring ([#8](https://github.com/jasonwong1991/WonderBox/issues/8), implemented in [#9](https://github.com/jasonwong1991/WonderBox/pull/9)).

## 更新 / Updating

要求 **macOS 14 或更新版本**。`WonderBox-1.1.0.zip` 同时包含 **Apple Silicon 和 Intel** 二进制；SHA-256 校验值见附件 `SHA256SUMS`。

Requires **macOS 14 or newer**. `WonderBox-1.1.0.zip` includes **Apple Silicon and Intel** binaries; its SHA-256 checksum is in the attached `SHA256SUMS`.

退出 WonderBox，解压 ZIP，替换“应用程序”中的 `WonderBox.app`，然后重新打开。已有卸载监听插件的用户，可在 **设置 → 卸载监听插件 → 重启插件** 切换到新版插件，待确认记录会保留。

Quit WonderBox, unzip the archive, replace `WonderBox.app` in Applications, and reopen it. If the uninstall watcher is installed, use **Settings → Uninstall Watcher Plugin → Restart Plugin** to adopt the updated helper while preserving pending reviews.

## 验证与兼容性 / Validation and Compatibility

- 321 项自动测试无失败（5 项环境／权限相关测试跳过），7 项打包测试通过；解压后再次验证版本、双架构、签名和中文资源。本机只读实测验证了整机、CPU、GPU 数据，并检查了紧凑／宽窗口的浅色和深色布局。

  321 automated tests completed with zero failures and five environment/permission-related skips; all seven packaging tests passed. Version metadata, both architectures, signatures and Chinese resources were checked again after extracting the ZIP. Read-only host sampling verified system, CPU and GPU data, and compact/wide layouts were inspected in light and dark appearances.

- 传感器支持取决于机型和 macOS。沙盒构建中不采集这些私有接口读数。Intel 真机、macOS 14 及其他系统版本的手动传感器验收尚未完成；通用二进制构建不代表每种硬件的数据源都已验证。

  Sensor availability depends on hardware and macOS. Sandboxed builds do not collect these private-API readings. Manual sensor acceptance on Intel hardware, macOS 14 and other OS versions remains outstanding; a universal build does not establish sensor coverage on every machine.

  This release remains **ad-hoc signed and not notarized**, like previous versions.
