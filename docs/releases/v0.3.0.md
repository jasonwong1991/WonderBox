# WonderBox 0.3.0

## 新增功能 / What’s New

- 新增 CPU 与 GPU 监控页面，提供逐应用使用率排行、辅助进程归并、搜索和退出操作。

  CPU and GPU monitoring pages with per-app usage rankings, helper-process aggregation, search, and quit actions.

- 新增 GPU 概览卡片与设备信息。

  GPU overview card and device information.

- 独立的开机启动设置，展示批准状态并提供系统登录项入口。

  Dedicated startup settings with approval status and a system Login Items shortcut.

- 卸载页支持展开关联文件分组与文件夹预览。

  Expandable related-file groups and folder previews in the uninstaller.

## 修复 / Fixes

- 修复浏览器下载后特权 helper 的启动问题（#5，感谢 @EveSunMaple）。

  Fix privileged helper startup after browser downloads (#5, thanks @EveSunMaple).

- 移除受保护应用时复用已授权 helper，并保留卸载结果消息。

  Reuse the authorized helper for protected app removal and keep uninstall results visible.

- 完善用户、系统及临时目录中的关联文件发现。

  Improve related-file discovery across user, system, and temporary locations.

- 重试暂时失败的首次风扇读数，并区分停转风扇与不可用传感器。

  Retry transient initial fan readings and distinguish stopped fans from unavailable sensors.

- 修复侧边栏标签截断；系统运行时间与“系统信息”一致，包含睡眠时间。

  Fix sidebar label truncation and match system uptime to System Information, including sleep.

- 根据 ZIP 内容识别安装包，不再只看扩展名。

  Identify ZIP installers by contents instead of extension alone.

- 合并“全选 / 取消全选”；“完成”保存更改，“关闭”或 Escape 保留原选择。

  Combine Select All / Deselect All; Done saves changes, while Close or Escape preserves the original selection.

## 安装 / Installation

要求 **macOS 14 或更新版本**，提供支持 **Apple Silicon 和 Intel** 的通用构建。

Requires **macOS 14 or newer**. Universal build for **Apple Silicon and Intel**.

退出 WonderBox，解压安装包，替换“应用程序”中的 `WonderBox.app` 后重新打开。此版本使用 ad-hoc 临时签名、未公证；首次启动请参考[安装说明](https://github.com/jasonwong1991/WonderBox/blob/v0.3.0/README.zh-CN.md)。更新共享 helper 需要一次管理员授权；逐进程 GPU 指标取决于驱动支持。

Quit WonderBox, unzip the archive, replace `WonderBox.app` in Applications, and relaunch. This build is ad-hoc signed and not notarized; see the [installation instructions](https://github.com/jasonwong1991/WonderBox/blob/v0.3.0/README.md#install) for first-launch setup. Updating the shared helper requires one administrator authorization. Per-process GPU metrics depend on driver support.
