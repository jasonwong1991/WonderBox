# WonderBox 1.2.2

构建号：**122**。优化 CPU 功耗的数据源兼容性和首次采样，修复只识别 `CPU Energy` 单一名称导致部分机器有 GPU 功耗、却缺少 CPU 功耗的问题。

Build **122**. Improves CPU power compatibility and initial sampling. The previous implementation recognized only `CPU Energy`, which could leave CPU power unavailable while GPU power worked on machines exposing different CPU counters.

## CPU 功耗优化 / CPU Power Improvements

- 支持整颗 CPU 总计、Ultra 等机型的分芯片总计，以及 ECPU／PCPU 等完整核心类型能量计数。优先使用整体总计，不把总计、分芯片和核心分项重复相加。

  Supports whole-CPU energy, per-die totals on multi-die machines, and complete core-type families such as ECPU/PCPU. A whole-CPU total takes priority; overlapping total, die and core-type readings are never added together.

- 首次采样会自动建立能量基线，等待约 **0.6 秒**后取得真实差值；测量期间显示“正在测量功耗…”。不必手动刷新来获得第二次采样。

  Initial sampling establishes an energy baseline and obtains a measured delta after approximately **0.6 seconds**. The initial refresh shows “Measuring power…”, without requiring a manual refresh for a second sample.

- 保留单位换算、实际采样间隔校验、数据缺口和数据源变化断线处理。重复、无效或不完整的计数不会被当成整颗 CPU 功耗；没有可靠数据源时仍显示 `—`。不估算瓦数，不新增管理员授权。

  Unit conversion, actual elapsed-time validation and chart gaps remain in place. Duplicate, invalid or incomplete counters are not presented as whole-CPU power. Unsupported readings remain `—`; no watts are guessed and no administrator prompt is added.

## 更新 / Updating

要求 **macOS 14 或更新版本**。退出旧版，解压 **Apple Silicon／Intel 通用版** `WonderBox-1.2.2.zip`，替换“应用程序”中的 `WonderBox.app` 后重新打开。SHA-256 校验值见 `SHA256SUMS`。

Requires **macOS 14 or newer**. Quit the old version, unzip the **universal Apple Silicon / Intel** `WonderBox-1.2.2.zip`, replace `WonderBox.app` in Applications, and reopen it. The SHA-256 checksum is included in `SHA256SUMS`.

## 验证范围 / Validation Scope

340 项自动测试零失败（5 项环境／权限相关测试跳过），7 项打包测试通过，Apple Silicon／Intel 通用构建成功。

340 automated tests completed with zero failures and five environment/permission-related skips; all seven packaging tests passed, and the Apple Silicon / Intel universal build succeeded.

回归样本覆盖 CPU 名称变体、分芯片和核心类型计数、重复／不完整来源及启动基线；原生只读测试验证了本机首次采样的 CPU 功耗。反馈截图对应的芯片和系统版本尚未提供，仍需在该机器上确认；其他机型和 macOS 14 的手动兼容性验收也待补充。

Regression fixtures cover CPU name variants, die/core-type counters, duplicate/incomplete sources and initial baselines. A native read-only check verified CPU power on the first primed sample on the development host. The reporting machine’s chip and macOS version were not supplied, so confirmation on that machine remains outstanding, as do manual compatibility checks on other hardware and macOS 14.
