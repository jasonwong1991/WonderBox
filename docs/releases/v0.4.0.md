# WonderBox 0.4.0

## 新增功能 / What’s New

- **响应更快的磁盘浏览**：先显示文件夹内容，再增量计算大小；切换目录时取消旧扫描，并复用近期查看的列表。

  **Responsive disk browsing:** show folder contents first, calculate sizes incrementally, cancel old scans on navigation, and reuse recently viewed listings.

- **按应用选择缓存**：展示应用名称、图标和缓存总大小，支持展开缓存文件夹、搜索及部分选择。“全选”仅作用于可见结果，“关闭”保留原选择。

  **App-based cache selection:** application names, icons, and total cache sizes, with expandable cache folders, search, and partial selection. Select All applies to visible results; Close preserves previous choices.

- **微信与企业微信缓存清理**：支持的应用/网页缓存分为独立的可选分类。排除聊天数据库、附件以及账号/配置根目录；所选缓存移入废纸篓。

  **WeChat and WeCom cache cleanup:** separate opt-in categories for supported application/web caches. Chat databases, attachments, and account/profile roots are excluded; selected caches go to the Trash.

## 改进 / Improvements

- 移入废纸篓前再次检查聊天应用及后台辅助进程，涵盖确认后才启动的应用。

  Recheck messaging apps and background helpers immediately before moving caches, including apps started after confirmation.

- 缓存清理仅限支持的目录布局，并拒绝符号链接路径。

  Restrict cache cleanup to supported directory layouts and reject symlinked paths.

- 失败或不完整的目录大小估算继续标记为未知值或下限。

  Keep failed or incomplete directory size estimates marked as unknown or lower bounds.

- 重新扫描后保留清理结果消息。

  Preserve cleanup result messages after rescanning.

## 安装 / Installation

要求 **macOS 14 或更新版本**，提供支持 **Apple Silicon 和 Intel** 的通用构建。

Requires **macOS 14 or newer**. Universal build for **Apple Silicon and Intel**.

退出 WonderBox，解压安装包，替换“应用程序”中的 `WonderBox.app` 后重新打开。此版本使用 ad-hoc 临时签名、未公证，请参考[安装说明](https://github.com/jasonwong1991/WonderBox/blob/v0.4.0/README.zh-CN.md)。应用签名身份变更后，可能需要一次管理员授权来更新共享 helper。

Quit WonderBox, unzip the archive, replace `WonderBox.app` in Applications, and relaunch. The build is ad-hoc signed and not notarized; see the [installation instructions](https://github.com/jasonwong1991/WonderBox/blob/v0.4.0/README.md#install). A changed app signing identity may require one administrator authorization to refresh the shared helper.

## 验证 / Validation

75 项测试通过；通用二进制、签名与安装包完整性均已校验。微信缓存发现已在本机检查；企业微信目录布局已通过测试样本验证，使用已安装企业微信客户端的验证仍待完成。

75 tests passed; universal binaries, signatures, and archive integrity were verified. WeChat discovery was checked locally. WeCom layouts are fixture-tested; validation against an installed WeCom client is pending.
