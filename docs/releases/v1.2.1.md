# WonderBox 1.2.1

构建号：**121**。移除缺少可靠数据源的风扇功耗展示，功耗页保留整机、CPU 和 GPU 的实际可用读数。

Build **121**. Removes the fan-power display because it has no supported measurement source. The Power page keeps available system, CPU and GPU readings.

## 功耗展示优化 / Power Display Cleanup

- 移除始终显示 `—` 的风扇功耗卡片，以及功耗采样中附带的风扇转速读取。不会根据 RPM 猜测瓦数。

  Removes the fan-power card that always showed `—`, along with the fan-RPM reads attached to power sampling. Wattage is never guessed from RPM.

- 风扇页和菜单栏浮窗继续显示实际转速。自动模式下系统可能让风扇停转，此时真实的 **0 RPM** 仍正常显示；进入风扇页不会新增管理员授权请求，也不会切换控制模式。

  The Fan page and menu bar popup continue to show actual fan speed. macOS can stop fans in automatic mode, so genuine **0 RPM** readings remain valid. Opening the Fan page introduces no administrator prompt or mode change.

## 安装 / Installation

要求 **macOS 14 或更新版本**。`WonderBox-1.2.1.zip` 为 **Apple Silicon／Intel 通用版**。退出旧版，解压并替换“应用程序”中的 `WonderBox.app` 后重新打开。SHA-256 校验值见附件 `SHA256SUMS`。

Requires **macOS 14 or newer**. `WonderBox-1.2.1.zip` is a **universal Apple Silicon / Intel** archive. Quit the old version, unzip and replace `WonderBox.app` in Applications, then reopen it. The SHA-256 checksum is attached as `SHA256SUMS`.

333 项自动测试零失败（5 项环境／权限相关测试跳过），7 项打包测试通过；已检查浅色／深色功耗页。Intel 真机及 macOS 14 的手动兼容性验收仍待补充。

333 automated tests completed with zero failures and five environment/permission-related skips; all seven packaging tests passed. The Power page was inspected in light and dark appearances. Manual compatibility checks on Intel hardware and macOS 14 remain outstanding.
