# WonderBox 1.2.3

构建号：**123**。针对 **M6 + macOS 27.2（26B123）** 接入新的 CPU 功耗读取路径。

Build **123**. Adds a CPU-power path for **M6 + macOS 27.2 (26B123)**.

## CPU 功耗兼容 / CPU Power Compatibility

- macOS 27 的旧 Energy Model CPU 计数可能不再更新。此次接入 CLPC CPU 总能量报告，使用实际驱动标识、运行时 DriverID 和精确系统构建匹配；按能量差值和真实间隔换算瓦数，不从整机或 GPU 功耗推算 CPU 数值。

  Legacy Energy Model CPU counters can stop updating on macOS 27. This version adds a CLPC CPU aggregate, matched by driver identifier, live DriverID and exact OS build. Watts come from measured energy deltas and actual elapsed time, not an estimate from system/GPU power.

- 报告编号已从 **Apple 官方 macOS 27.2 固件**中独立识别，限定适用于 `AppleT8152CLPC` 与构建 `26B123`。未知驱动或系统构建不套用编号；保留实际可用的 SMC 回退，缺失或无效读数继续显示 `—`。

  The report identity was independently identified from **Apple's macOS 27.2 firmware** and is limited to `AppleT8152CLPC` / build `26B123`. Unknown drivers/builds do not reuse the mapping. Available SMC fallbacks remain, and missing/invalid readings stay `—`.

- CLPC 总计不会与旧 CPU 能量重复相加；有效零值保留，负值、重复报告、计数重置或不符的单位会被排除。GPU 和整机功耗的来源保持独立。

  CLPC power is not added to overlapping legacy CPU totals. Valid zeroes are preserved; negative values, duplicate reports, resets and invalid units are rejected. GPU and system readings remain separate.

- 不新增管理员授权，不安装新辅助服务，也不通过切换风扇模式取得数据。

  No new administrator prompt, helper installation or fan-mode change is introduced.

## 验证范围 / Validation Scope

344 项自动测试零失败（5 项环境／权限相关测试跳过），7 项打包测试通过；Apple Silicon／Intel 通用构建成功。

344 automated tests completed with zero failures and five environment/permission-related skips; all seven packaging tests passed, and the Apple Silicon / Intel universal build succeeded.

已核验官方固件的来源、哈希、驱动 UUID 和 CPU 报告依赖关系，另用原生 IOReport 校验描述符的单位和标识。**尚未在反馈用户的 M6 真机上实测**：静态报告识别与自动测试不代表实际读取权限和测量精度已经验证，仍需升级后确认空闲、负载及睡眠唤醒时的表现。

The official firmware source, hashes, driver UUID and CPU report dependency trace were checked, and native IOReport getters validated descriptor units and identities. **Runtime measurement on the reporting M6 remains unverified**: static identity and automated tests do not establish access or accuracy on that device. Idle, load and sleep/wake behavior still need confirmation after updating.

## 更新 / Updating

要求 **macOS 14 或更新版本**。退出旧版，解压 **Apple Silicon／Intel 通用版** `WonderBox-1.2.3.zip` 并替换 `WonderBox.app`，然后重新打开。SHA-256 校验值见附件 `SHA256SUMS`。

Requires **macOS 14 or newer**. Quit the old version, unzip the **universal Apple Silicon / Intel** `WonderBox-1.2.3.zip`, replace `WonderBox.app`, and reopen it. The SHA-256 checksum is attached as `SHA256SUMS`.
