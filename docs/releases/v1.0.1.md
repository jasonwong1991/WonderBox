# WonderBox 1.0.1

构建号：101。本次是 0.6.0 之后首次发布的 1.0 系列稳定版，包含温度监控、可选卸载监听插件、自动清理，以及卸载体验修复。

## 菜单栏图标由用户选择

- 在 **设置 → 常驻 → 菜单栏图标** 中选择 **彩色** 或 **单色**，切换立即生效，重启后保留选择。
- 默认沿用原有彩色图标，不强制改变现有外观；单色图标使用 macOS 模板图像，跟随系统菜单栏外观。

## 1.0 新功能

- **温度监控**：风扇页和菜单栏显示 CPU/GPU 温度摘要与实际传感器读数；缺失的传感器保持不可用，不推算每核温度。
- **可选卸载监听插件**：首次启动询问是否安装，也可在设置中安装或卸载；独立登录项在 WonderBox 退出后仍可监听应用删除，关联文件只在用户确认后移入废纸篓。
- **一键清理预估**：菜单栏浮窗显示默认清理分类的预计可回收量，清理后重新估算；实际释放空间可能不同。
- **自动清理**：默认关闭，首次进入空间清理时询问。支持缓存大小、时间间隔或任一条件；仅处理已识别且未运行应用的可重建缓存。WonderBox 退出后暂停，重新打开后恢复检查。

## 全选与响应速度

- 主界面与外部删除确认窗均提供“全选 / 取消全选”和选中数量；大小计算在后台进行，不会覆盖用户勾选。
- 监听改用递归 FSEvents。书签确认应用已移入废纸篓时立即通知，不再固定等待 30 秒。未确认去向的路径消失保留 8 秒保护期，避免一般的应用更新误报；仍保留低频兜底检查。
- 确认移除前不再多次扫描全部应用和全部关联目录：重装检查只读取必要元数据，不创建全盘应用书签；选中的文件用原始 inode/type 校验，变更后的替代文件需重新扫描确认。
- 应用清单先显示元数据，缺失索引大小时不再阻塞在完整包遍历上；后台测量有统一预算，部分大小继续标记 `≥`。
- 卸载完成只更新受影响的应用，取消全列表重扫等待。完整目录列表已覆盖的文件不再重复执行大量精确路径探测。

## Cookies 删除与权限

此前插件弹窗直接调用 Finder，跳过了主应用的直接移入废纸篓路径，可能出现管理员鉴权后仍收到 Finder `-5000`。现与主界面统一：先使用当前 WonderBox 自身权限，普通失败再交给 Finder。

Cookies 路径被拒绝时不重复要求管理员密码，而是保留失败项目、处理其他所选文件，并提供完全磁盘访问指引。管理员认证不等于 macOS 隐私授权。不可读目录中的猜测文件名不再被列为真实关联文件。

## 更新

要求 **macOS 14 或更新版本**，安装包同时包含 **Apple Silicon 和 Intel** 二进制。

退出 WonderBox，解压 `WonderBox-1.0.1.zip`，替换“应用程序”中的 `WonderBox.app` 并打开。已经安装卸载监听插件的用户，请在“设置 → 卸载监听插件”点击 **重启插件**，使已运行的旧插件进程切换到新版；不会清除等待确认的记录。

ZIP 的 SHA-256 校验值见 Release 附件 `SHA256SUMS`。安装与权限说明见 [README](https://github.com/jasonwong1991/WonderBox/blob/v1.0.1/README.zh-CN.md)。
