# WonderBox 1.0.1

构建号：**101**。本次是 0.6.0 之后首次发布的 1.0 系列稳定版，包含温度监控、可选卸载监听插件、自动清理，以及卸载体验修复。

Build **101**. This is the first published stable release in the 1.0 series since 0.6.0, including temperature monitoring, an optional uninstall watcher plugin, automatic cleanup, and uninstall improvements.

## 菜单栏图标由用户选择 / Your Choice of Menu Bar Icon

- 在 **设置 → 常驻 → 菜单栏图标** 中选择 **彩色** 或 **单色**，切换立即生效，重启后保留选择。

  Choose **Color** or **Monochrome** under **Settings → Always Available → Menu bar icon**. Changes apply immediately and are remembered across launches.

- 默认沿用原有彩色图标，不强制改变现有外观；单色图标使用 macOS 模板图像，跟随系统菜单栏外观。

  The original color icon remains the default, with no forced appearance change. The monochrome icon uses a macOS template image and follows the system menu bar appearance.

## 1.0 新功能 / New in 1.0

- **温度监控**：风扇页和菜单栏显示 CPU/GPU 温度摘要与实际传感器读数；缺失的传感器保持不可用，不推算每核温度。

  **Temperature monitoring:** the Fan page and menu bar show CPU/GPU temperature summaries and actual sensor readings. Missing sensors remain unavailable; per-core temperatures are not estimated.

- **可选卸载监听插件**：首次启动询问是否安装，也可在设置中安装或卸载；独立登录项在 WonderBox 退出后仍可监听应用删除，关联文件只在用户确认后移入废纸篓。

  **Optional uninstall watcher plugin:** offered on first launch and installable/removable in Settings. A separate login item watches app removals even after WonderBox quits. Related files move to the Trash only after user confirmation.

- **一键清理预估**：菜单栏浮窗显示默认清理分类的预计可回收量，清理后重新估算；实际释放空间可能不同。

  **Quick Clean estimate:** the menu bar panel shows estimated reclaimable space for the default cleanup categories and recalculates it after cleanup. Actual reclaimed space may differ.

- **自动清理**：默认关闭，首次进入空间清理时询问。支持缓存大小、时间间隔或任一条件；仅处理已识别且未运行应用的可重建缓存。WonderBox 退出后暂停，重新打开后恢复检查。

  **Automatic cleanup:** off by default, with a prompt on the first visit to Cleanup. Trigger by cache size, time interval, or either condition. Only rebuildable caches belonging to identified apps that are not running are included. Checks pause when WonderBox quits and resume when it reopens.

## 全选与响应速度 / Selection and Responsiveness

- 主界面与外部删除确认窗均提供“全选 / 取消全选”和选中数量；大小计算在后台进行，不会覆盖用户勾选。

  Both the main uninstall interface and external-removal review provide Select All / Deselect All and a selected-item count. Background size measurement does not overwrite user selections.

- 监听改用递归 FSEvents。书签确认应用已移入废纸篓时立即通知，不再固定等待 30 秒。未确认去向的路径消失保留 8 秒保护期，避免一般的应用更新误报；仍保留低频兜底检查。

  The watcher uses recursive FSEvents. A bookmark confirming that an app has moved to the Trash triggers an immediate notification instead of a fixed 30-second wait. Unconfirmed path disappearance retains an eight-second grace period to avoid false positives during ordinary app updates; low-frequency fallback checks remain.

- 确认移除前不再多次扫描全部应用和全部关联目录：重装检查只读取必要元数据，不创建全盘应用书签；选中的文件用原始 inode/type 校验，变更后的替代文件需重新扫描确认。

  Removal confirmation no longer repeatedly scans all apps and related directories. Reinstallation checks read only required metadata without creating bookmarks for the full inventory. Selected files are checked against their original inode/type; replacement objects must be rescanned and reviewed.

- 应用清单先显示元数据，缺失索引大小时不再阻塞在完整包遍历上；后台测量有统一预算，部分大小继续标记 `≥`。

  The app list shows metadata first instead of blocking on full bundle traversal when indexed sizes are missing. Background measurement has a shared budget; partial sizes remain marked with `≥`.

- 卸载完成只更新受影响的应用，取消全列表重扫等待。完整目录列表已覆盖的文件不再重复执行大量精确路径探测。

  After uninstall, only the affected app is updated instead of waiting for a full inventory rescan. Files already covered by complete directory listings no longer trigger repeated exact-path probes.

## Cookies 删除与权限 / Cookie Removal and Permissions

此前插件弹窗直接调用 Finder，跳过了主应用的直接移入废纸篓路径，可能出现管理员鉴权后仍收到 Finder `-5000`。现与主界面统一：先使用当前 WonderBox 自身权限，普通失败再交给 Finder。

Previously, the plugin review called Finder directly, bypassing the main app’s direct Trash API, which could result in Finder error `-5000` even after administrator authentication. Both interfaces now use the current WonderBox app’s own permissions first and send ordinary failures to Finder.

Cookies 路径被拒绝时不重复要求管理员密码，而是保留失败项目、处理其他所选文件，并提供完全磁盘访问指引。管理员认证不等于 macOS 隐私授权。不可读目录中的猜测文件名不再被列为真实关联文件。

Cookie access denials no longer cause repeated administrator password prompts. Failed items are retained, other selected files are processed, and Full Disk Access guidance is shown. Administrator authentication does not grant macOS privacy access. Guessed filenames inside unreadable directories are no longer listed as real related files.

## 更新 / Updating

要求 **macOS 14 或更新版本**，安装包同时包含 **Apple Silicon 和 Intel** 二进制。

Requires **macOS 14 or newer**. The archive includes binaries for both **Apple Silicon and Intel**.

退出 WonderBox，解压 `WonderBox-1.0.1.zip`，替换“应用程序”中的 `WonderBox.app` 并打开。已经安装卸载监听插件的用户，请在“设置 → 卸载监听插件”点击 **重启插件**，使已运行的旧插件进程切换到新版；不会清除等待确认的记录。

Quit WonderBox, unzip `WonderBox-1.0.1.zip`, replace `WonderBox.app` in Applications, and reopen it. If the uninstall watcher plugin is already installed, click **Restart Plugin** under **Settings → Uninstall Watcher Plugin** to switch the running helper to the new version. Pending reviews are preserved.

ZIP 的 SHA-256 校验值见 Release 附件 `SHA256SUMS`。安装与权限说明见 [README](https://github.com/jasonwong1991/WonderBox/blob/v1.0.1/README.zh-CN.md)。

The ZIP’s SHA-256 checksum is included in the Release attachment `SHA256SUMS`. See the [README](https://github.com/jasonwong1991/WonderBox/blob/v1.0.1/README.md) for installation and permissions.

## 验证与分发说明 / Validation and Distribution Notes

自动测试覆盖图标选择与保存、卸载选择和扫描、监听事件、自动清理边界、温度有效性、中文翻译及打包结构；测试不安装登录项或批准系统权限对话框。macOS 14、Intel 硬件及系统权限交互的手动兼容性验收仍需分别完成，详见[分发检查清单](https://github.com/jasonwong1991/WonderBox/blob/v1.0.1/docs/DISTRIBUTION.md)。

Automated tests cover icon selection and persistence, uninstall selection and scanning, watcher events, automatic-cleanup boundaries, temperature validation, Chinese translations, and packaging structure. Tests do not install login items or approve system permission dialogs. Manual compatibility checks on macOS 14, Intel hardware, and system permission interactions still need to be completed separately; see the [distribution checklist](https://github.com/jasonwong1991/WonderBox/blob/v1.0.1/docs/DISTRIBUTION.md).

此版本沿用 **ad-hoc 临时签名，未公证**。实际受保护 Cookies 的访问仍取决于系统对当前应用副本的隐私授权；管理员认证不替代隐私授权。

This release remains **ad-hoc signed and not notarized**. Access to protected Cookies still depends on the system’s privacy authorization for the current app copy; administrator authentication does not replace privacy permission.
