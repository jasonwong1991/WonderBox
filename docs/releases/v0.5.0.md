# WonderBox 0.5.0

## 新增功能 / New Features

- 在线检查和下载 GitHub 正式版更新，支持进度、取消、重试及 SHA-256 校验；下载后由用户替换安装，不自动安装。

  Check for and download stable GitHub releases, with progress, cancellation, retries, and SHA-256 verification. Users replace the app after downloading; updates are not installed automatically.

- 本地诊断日志支持导出、清空和关闭，总量上限 2 MiB、最长保留 7 天；不记录文件路径、应用名称或账号，不自动上传。

  Local diagnostic logs can be exported, cleared, or disabled, with a 2 MiB size limit and seven-day retention. Logs do not record file paths, app names, or accounts and are never uploaded automatically.

## 改进与修复 / Improvements and Fixes

- 修复部分 root 所有的应用卸载失败：普通移除失败后由 Finder 处理，并改善管理员验证窗口的焦点交接。

  Fix uninstall failures for some root-owned apps: Finder handles failures from the ordinary removal API, with improved focus handoff to the administrator authentication dialog.

- 完善应用关联文件发现，包括沙盒与 UUID 容器；支持清理已在废纸篓中的应用残留，保留失败项目及勾选状态供重试。

  Improve related-file discovery, including sandbox and UUID containers. Clean leftovers of apps already in the Trash while preserving failed items and their selections for retry.

- 修复卸载错误消息撑大窗口的问题，提供完整错误详情和未移除项目的 Finder 定位入口。

  Fix uninstall error messages expanding the window; provide full error details and Reveal in Finder actions for items that were not removed.

- 应用缓存详情支持按名称、大小排序，保持原有勾选项；统一开机启动设置的布局。

  Sort app-cache details by name or size while preserving selections, and unify the startup settings layout.

- CPU/GPU 使用率改为全宽、最近 60 秒的滚动曲线，显示时间与百分比刻度。

  Display CPU/GPU usage as full-width rolling charts for the last 60 seconds, with time and percentage axes.

- 工具栏刷新与 ⌘R 改为刷新当前页面；磁盘分析重扫当前目录，CPU/GPU 和内存同步刷新应用排行。

  The toolbar refresh action and ⌘R refresh the current page. Disk Analyzer rescans the current directory; CPU/GPU and memory pages also refresh their app rankings.

## 安装 / Installation

要求 **macOS 14 或更新版本**，支持 **Apple Silicon 和 Intel**。

Requires **macOS 14 or newer**, with support for **Apple Silicon and Intel**.

退出 WonderBox，解压 `WonderBox-0.5.0.zip`，替换“应用程序”中的 `WonderBox.app` 后重新打开。

Quit WonderBox, unzip `WonderBox-0.5.0.zip`, replace `WonderBox.app` in Applications, and relaunch.

此版本仍为临时签名（ad-hoc）、未公证构建，安装说明见 [README](https://github.com/jasonwong1991/WonderBox/blob/v0.5.0/README.zh-CN.md)。更新后 macOS 可能要求重新确认权限；移除受保护应用时可能需要允许控制 Finder，并完成系统管理员验证。

This build remains ad-hoc signed and not notarized; see the [README](https://github.com/jasonwong1991/WonderBox/blob/v0.5.0/README.md) for installation instructions. macOS may require renewed permissions after updating. Removing protected apps may require permission to control Finder and system administrator authentication.
