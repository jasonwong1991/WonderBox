# WonderBox 1.2.4

构建号：**124**。在概览和菜单栏查看整机功耗，并统一 README 的截图与排版。

Build **124**. System power in Overview and the menu bar, plus refreshed README screenshots and formatting.

## 整机功耗 / System Power

- 概览新增整机功耗卡片，显示实时瓦数与传感器来源；点击详情按钮即可进入功耗页。概览刷新同时更新普通指标与功耗，不另开采样器。

  Overview gains a system-power card with live watts and the sensor source. Its detail button opens the Power page, and Overview refresh updates both ordinary metrics and power without creating another sampler.

- 菜单栏新增独立的系统功耗选项，与 CPU、内存显示分开控制，默认关闭。在「设置 → 常驻」开启后，即使主窗口关闭也会约每三秒更新。

  The menu bar gains an independent system-power option, separate from CPU and RAM and off by default. Enable it in Settings → Always Available for updates approximately every three seconds, including with the main window closed.

- 两处整机功耗均使用功耗页同源的 SMC PSTR 传感器，不把 CPU＋GPU、充电功率或适配器输入当作整机功耗。菜单栏使用轻量采样，不启动 CPU/GPU 能量订阅、进程扫描或功耗历史。缺失或过期读数显示 `—`，真实零值保留。

  Both system readings use the same SMC PSTR source as the Power page, not CPU + GPU, charging power or adapter input. The lightweight menu-bar sampler does not start CPU/GPU energy subscriptions, process scans or power history. Missing or stale readings show `—`; measured zero remains zero.

## 验证范围 / Validation Scope

350 项自动测试零失败（10 项环境或显式启用测试跳过），7 项打包测试通过，本地化检查通过。主应用、两个辅助程序和卸载监测插件均包含 arm64／x86_64；ZIP 解压后已复核版本、签名、辅助程序身份约束与中文资源。

350 automated tests completed with zero failures and 10 environment/opt-in skips; all seven packaging tests and localization checks passed. The app, both helpers and the uninstall watcher contain arm64/x86_64 slices. Version metadata, signatures, helper identity requirements and Chinese resources were rechecked after extracting the ZIP.

本轮在 Apple M4 Max / macOS 26.5.2 上验证真实界面与读数。传感器支持因机型和系统版本而异；通用构建与自动测试不代表其他 Mac 或 macOS 版本已经完成真机验证。

Native UI and readings were checked on an Apple M4 Max / macOS 26.5.2. Sensor support varies by hardware and OS; universal compilation and automated tests do not establish runtime validation on other Macs or macOS versions.

## 更新 / Updating

要求 **macOS 14 或更新版本**。退出旧版，解压 **Apple Silicon／Intel 通用版** `WonderBox-1.2.4.zip`，替换 `WonderBox.app` 后重新打开。校验值见附件 `SHA256SUMS`。

Requires **macOS 14 or newer**. Quit the old version, unzip the **universal Apple Silicon / Intel** `WonderBox-1.2.4.zip`, replace `WonderBox.app`, and reopen it. Checksums are attached as `SHA256SUMS`.

沿用 **ad-hoc 临时签名，未公证**；更新程序不会自动安装或运行下载的应用。

This release remains **ad-hoc signed and not notarized**. The updater does not automatically install or run the downloaded app.
