# WonderBox 1.0.0

## 1.0 新功能 / New in 1.0

- **温度监控**：风扇页新增 CPU/GPU 温度摘要及逐项传感器读数；菜单栏浮窗同步显示温度。Intel 核心键可显示核心序号，其余机型保留真实 SMC 键名；传感器覆盖依机型而定，不推算缺失核心温度。

  **Temperature monitoring:** the Fan page adds CPU/GPU summaries and individual sensor readings, also shown in the menu bar panel. Recognized Intel core keys can show core numbers; other machines retain actual SMC keys. Sensor coverage varies by model; missing core temperatures are not estimated.

- **卸载监听插件**：首次启动提供可选安装提示；独立 macOS 登录项监听 `/Applications` 和 `~/Applications`。应用在 Finder 中删除或移入废纸篓后，打开关联文件确认窗；WonderBox 退出后仍可监听。设置中可安装、卸载或前往系统批准登录项。

  **Uninstall watcher plugin:** offered as an optional install on first launch. A separate macOS login item watches `/Applications` and `~/Applications`, opening a related-file review when an app is deleted or moved to the Trash in Finder, even after WonderBox quits. Settings offers installation, removal, and a shortcut to system login-item approval.

- **避免误报**：应用改名、移动、重复安装与短暂更新替换不视作卸载；应用移除后等待 30 秒确认。读取失败不作删除依据，确认清理前再次检查应用是否恢复、重装或运行。

  **Avoid false positives:** app renames, moves, duplicate installations, and temporary update replacements are not treated as uninstalls. Removals wait 30 seconds for confirmation. Read failures are not evidence of removal; before cleanup, the app is checked again for restoration, reinstallation, or running state.

- **一键清理预估**：浮窗显示默认一键清理项目的预计可回收量，清理后重新估算；与手动勾选结果分离，避免把深度扫描的选择误用到一键清理。

  **Quick Clean estimate:** the panel shows estimated reclaimable space for the default Quick Clean categories and recalculates it after cleanup. It stays separate from manual selections so deep-scan choices are not accidentally reused by Quick Clean.

- **自动清理**：默认关闭，首次进入空间清理时询问。支持缓存大小、时间间隔或任一条件；设置中可随时调整。仅清理已识别且未运行应用的可重建缓存，不处理聊天数据、下载文件、系统缓存或废纸篓。

  **Automatic cleanup:** off by default, with a prompt on the first visit to Cleanup. Trigger by cache size, time interval, or either condition and adjust it in Settings. Only rebuildable caches of identified apps that are not running are included; messaging data, downloads, system caches, and the Trash are excluded.

## 安装与运行 / Installation and Operation

版本号为 **1.0.0**，构建号 **100**。使用 macOS 14 或更新系统。卸载插件需要完整 `.app` 包，单独 `swift run` 不包含可注册的嵌入登录项。安装插件后，如系统显示待批准，请在“系统设置 → 通用 → 登录项与扩展”中允许。

Version **1.0.0**, build **100**. Requires macOS 14 or newer. The uninstall plugin requires the complete `.app` bundle; `swift run` does not include a registrable embedded login item. If approval is required after installation, allow it in System Settings → General → Login Items & Extensions.

自动清理每五分钟检查一次，在 WonderBox 主窗口或菜单栏驻留期间运行；退出主应用后暂停，重新打开后按保存的条件继续。需要登录后自动运行时，可同时开启设置中的“登录时启动”。关闭自动清理后不再开始下一个缓存项目；正在进行的单个文件系统操作会完成。

Automatic cleanup checks every five minutes while WonderBox is running through its main window or menu bar. Checks pause when the app quits and resume with saved conditions when it reopens. Enable Launch at login separately if desired. Disabling automatic cleanup prevents the next cache item from starting; the current filesystem operation finishes.

关联文件只在用户确认后移入废纸篓。卸载插件不要求管理员权限；移除受保护关联文件时仍由 macOS/Finder 确认权限。永久删除的应用可能缺少组件元数据，界面会提示扫描范围不完整。

Related files move to the Trash only after user confirmation. The uninstall plugin does not require administrator privileges; macOS/Finder still handles authorization for protected related files. Permanently deleted apps may lack component metadata, and the interface reports incomplete scan coverage.

打包脚本默认使用 ad-hoc 临时签名；1.0 正式版版本标记不等同于 Developer ID 签名、公证或已发布 GitHub Release。分发前仍需按 [分发说明](../DISTRIBUTION.md) 完成签名、系统登录项和手动验收。

Packaging defaults to ad-hoc signing. A 1.0 stable version label does not imply Developer ID signing, notarization, or a published GitHub Release. Signing, system login-item checks, and manual acceptance still follow the [distribution guide](../DISTRIBUTION.md) before distribution.
