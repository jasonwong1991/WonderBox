# WonderBox 0.6.0

## 改进与修复 / Improvements and Fixes

- **更完整的关联文件扫描**：补充自定义 Library 目录、内嵌组件、共享应用组、厂商子目录、Electron 运行时名称与旧数据迁移目录，以及最近文档记录、自动保存、XDG 数据、共享缓存子目录和外置插件。采用通用归属规则，不逐个应用维护路径白名单。

  **More complete related-file scanning:** cover custom Library directories, embedded components, shared app groups, vendor subdirectories, Electron runtime names and legacy migration directories, recent-document records, autosave data, XDG data, shared cache subdirectories, and external plugins. Use general ownership rules rather than per-app path whitelists.

- **总占用更直观**：应用大小和大小排序包含应用本体与已发现的关联数据，共享及嵌套目录避免重复计入汇总。

  **Clearer total storage usage:** app sizes and size sorting include both the app bundle and discovered related data. Shared and nested directories are not double-counted in totals.

- **卸载页性能优化**：先显示关联列表，再后台统计大小；自动统计限制为每应用合计 60 ms / 1,500 项，切换页面取消旧任务。完整大小按需计算，可停止，卸载不等待统计完成。

  **Faster uninstall pages:** show related files first, then measure sizes in the background. Automatic measurement is limited to 60 ms / 1,500 entries per app, with old tasks cancelled on navigation. Full measurements are on demand and stoppable; uninstall does not wait for sizing.

- **未全选提醒**：详情和卸载确认显示未勾选项目的数量与大小，明确这些项目将保留；“返回检查”保留原选择。共享、旧版本、恢复数据和插件默认待确认；未知大小显示“待统计”，部分大小用 `≥` 标注。

  **Unselected-item reminders:** details and uninstall confirmation show the count and size of unselected items and explain that they will be kept. Return to Review preserves selections. Shared data, old versions, recovery data, and plugins require confirmation by default; unknown sizes are marked pending and partial sizes use `≥`.

扫描覆盖范围及排除项见[关联文件说明](https://github.com/jasonwong1991/WonderBox/blob/v0.6.0/docs/RELATED_FILES.md)。任意自定义路径仍需归属证据，不保证零残留。

See the [related-file documentation](https://github.com/jasonwong1991/WonderBox/blob/v0.6.0/docs/RELATED_FILES.md) for coverage and exclusions. Arbitrary custom paths still require ownership evidence; complete removal of all leftovers is not guaranteed.

## 安装 / Installation

要求 **macOS 14 或更新版本**，支持 **Apple Silicon 和 Intel**。

Requires **macOS 14 or newer**, with support for **Apple Silicon and Intel**.

退出 WonderBox，解压 `WonderBox-0.6.0.zip`，替换“应用程序”中的 `WonderBox.app` 后重新打开。ZIP 的 SHA-256 校验值见 `SHA256SUMS`。

Quit WonderBox, unzip `WonderBox-0.6.0.zip`, replace `WonderBox.app` in Applications, and relaunch. The ZIP’s SHA-256 checksum is included in `SHA256SUMS`.

此版本仍为临时签名（ad-hoc）、未公证构建。更新后 macOS 可能要求重新确认权限；安装说明见 [README](https://github.com/jasonwong1991/WonderBox/blob/v0.6.0/README.zh-CN.md)。

This build remains ad-hoc signed and not notarized. macOS may require renewed permissions after updating; see the [README](https://github.com/jasonwong1991/WonderBox/blob/v0.6.0/README.md) for installation instructions.
