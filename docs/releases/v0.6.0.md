# WonderBox 0.6.0

## 改进与修复

- **更完整的关联文件扫描**：补充自定义 Library 目录、内嵌组件、共享应用组、厂商子目录、Electron 运行时名称与旧数据迁移目录，以及最近文档记录、自动保存、XDG 数据、共享缓存子目录和外置插件。采用通用归属规则，不逐个应用维护路径白名单。
- **总占用更直观**：应用大小和大小排序包含应用本体与已发现的关联数据，共享及嵌套目录避免重复计入汇总。
- **卸载页性能优化**：先显示关联列表，再后台统计大小；自动统计限制为每应用合计 60ms / 1,500 项，切换页面取消旧任务。完整大小按需计算，可停止，卸载不等待统计完成。
- **未全选提醒**：详情和卸载确认显示未勾选项目的数量与大小，明确这些项目将保留；“返回检查”保留原选择。共享、旧版本、恢复数据和插件默认待确认；未知大小显示“待统计”，部分大小用 `≥` 标注。

扫描覆盖范围及排除项见[关联文件说明](https://github.com/jasonwong1991/WonderBox/blob/v0.6.0/docs/RELATED_FILES.md)。任意自定义路径仍需归属证据，不保证零残留。

## 安装

要求 **macOS 14 或更新版本**，支持 **Apple Silicon 和 Intel**。

退出 WonderBox，解压 `WonderBox-0.6.0.zip`，替换“应用程序”中的 WonderBox.app 后重新打开。ZIP 的 SHA-256 校验值见 `SHA256SUMS`。

此版本仍为临时签名（ad-hoc）、未公证构建。更新后 macOS 可能要求重新确认权限；安装说明见 [README](https://github.com/jasonwong1991/WonderBox/blob/v0.6.0/README.zh-CN.md)。
