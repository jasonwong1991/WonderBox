# WonderBox 0.1.0

WonderBox 首次公开发布：一款原生 macOS 系统工具箱，真实呈现你的 Mac 状态。

First public release of WonderBox — a native macOS system toolkit that tells you the truth about your Mac.

## 亮点 / Highlights

- **真正减少压缩内存的内存优化**：root helper 发送 macOS 自身使用的内核级内存压力广播，让运行中的应用释放缓存；报告展示各类别优化前后的变化，并列出响应的应用。

  **Memory optimization that actually shrinks compressed memory:** a root helper sends the kernel-level memory-pressure broadcast macOS itself uses so running apps release their caches. The report shows before/after values by category and names the apps that responded.

- **逐应用内存归属**：辅助进程归并到所属应用，估算每个应用处于压缩内存或交换空间中的用量，并在同一行提供“退出 / 强制退出”。

  **Per-app memory attribution:** helper processes are rolled into their host app, with estimates of each app’s compressed and swapped memory and Quit / Force Quit actions in the same row.

- **发现数十 GB 的可清理空间**：支持包管理器缓存（npm、pnpm、uv、Cargo、Go、Gradle、Maven、CocoaPods 等）、Chromium/Electron 网页缓存、沙盒容器缓存、模拟器与 DeviceSupport 文件、应用残留及设备备份。每次删除均通过对应分类的根目录白名单检查；非可重建缓存的项目移入废纸篓。

  **Cleanup that finds tens of gigabytes:** package-manager caches (npm, pnpm, uv, Cargo, Go, Gradle, Maven, CocoaPods…), Chromium/Electron web caches, sandboxed container caches, simulator and DeviceSupport files, app leftovers, and device backups. Every deletion passes a per-category root-directory whitelist; anything that is not a rebuildable cache goes to the Trash.

- **应用卸载、磁盘分析、风扇控制（AppleSMC）、保持唤醒及菜单栏面板**，支持浅色/深色主题和四种强调色。

  **Uninstaller, Disk Analyzer, fan control (AppleSMC), Keep Awake, and a menu bar panel**, with light/dark themes and four accent colors.

- **英文与简体中文界面**：可跟随系统语言，也可在设置中为应用单独选择。

  **English and Simplified Chinese:** follow the system language or choose an app-specific language in Settings.

## 安装 / Installation

要求 **macOS 14 或更新版本**。ZIP 包含支持 **Apple Silicon 和 Intel** 的通用版 `WonderBox.app`。

Requires **macOS 14 or newer**. The ZIP contains a universal `WonderBox.app` for **Apple Silicon and Intel**.

安装包使用 **ad-hoc 临时签名，未公证**，首次启动会被 Gatekeeper 拦截。右键点击应用 → 打开，并在“系统设置 → 隐私与安全性”中确认，或执行以下命令：

The build is **ad-hoc signed and not notarized**, so Gatekeeper blocks the first launch. Right-click the app → Open and confirm in System Settings → Privacy & Security, or run:

```bash
xattr -dr com.apple.quarantine /Applications/WonderBox.app
```

风扇控制和内存优化会在首次使用时安装一个小型 root helper（需要一次管理员授权）。所有操作均在本机执行，不上传数据。

Fan control and memory optimization install a small root helper on first use (one administrator prompt). Everything runs locally; nothing is uploaded.
