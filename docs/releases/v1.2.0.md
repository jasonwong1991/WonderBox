# WonderBox 1.2.0

构建号：**120**。菜单栏资源监测已优化：现在可以直接在 macOS 顶部菜单栏查看 CPU 和内存占用，无需先打开浮窗。

Build **120**. Menu bar monitoring is improved: CPU and memory usage can now appear directly in the macOS menu bar without opening the popup.

## 开启方法 / How to Enable

打开 **设置 → 常驻**，保持 **菜单栏快捷入口** 开启，然后按需勾选：

Open **Settings → Always Available**, keep **Menu bar shortcut** enabled, and choose either or both:

- **在菜单栏显示 CPU 占用 / Show CPU usage in menu bar**
- **在菜单栏显示内存占用 / Show memory usage in menu bar**

两项都开启时显示为 `CPU 12% · RAM 64%`；也可以只显示 CPU 或内存。两项默认关闭，保留升级前的纯图标外观；切换立即生效，重启后保留设置。

With both enabled, the label reads like `CPU 12% · RAM 64%`. Either metric can also be shown alone. Both default off to preserve the previous icon-only appearance. Changes apply immediately and persist across relaunches.

## 本次优化 / Improvements

- 约每 **3 秒**刷新一次，关闭主窗口后仍持续更新，不依赖浮窗是否展开。

  Updates approximately every **three seconds**, including when the main window is closed and the popup is not open.

- 独立轻量采样仅读取 CPU 和内存计数，不会因此让磁盘、GPU、功耗或应用排行扫描持续运行。关闭两项显示或隐藏菜单栏快捷入口后停止该采样，重新显示入口时恢复已保存的选择。

  A lightweight sampler reads only CPU and memory counters; it does not keep disk, GPU, power or per-app scans running. Disabling both metrics or hiding the shortcut stops this sampler. Restoring the shortcut preserves the saved choices.

- CPU 显示整机处理器占用（0–100%），RAM 采用与现有面板相同的已用内存口径。启动或唤醒后，CPU 会先等待真实采样基线；缺失／无效读数显示 `—`，不伪装成零。

  CPU reports overall processor usage (0–100%); RAM uses the same used-memory definition as the existing panel. CPU waits for a real baseline after launch or wake. Missing/invalid readings show `—`, not a fabricated zero.

- 保留原有 **彩色／单色菜单栏图标** 选择，点击菜单栏仍打开原来的快捷浮窗。此次更新不自动开启登录启动、不安装新辅助服务，也不改变用户的清理设置。

  Existing **color/monochrome menu bar icons** and the click-to-open popup are preserved. This update does not enable launch at login, install a new helper, or change cleanup preferences.

感谢 Issue [#10](https://github.com/jasonwong1991/WonderBox/issues/10) 提出的使用建议。

Thanks for the suggestion in Issue [#10](https://github.com/jasonwong1991/WonderBox/issues/10).

## 安装与验证 / Installation and Validation

要求 **macOS 14 或更新版本**。`WonderBox-1.2.0.zip` 为 **Apple Silicon／Intel 通用版**。退出旧版，解压并替换“应用程序”中的 `WonderBox.app`，重新打开后按上述步骤开启所需显示。

Requires **macOS 14 or newer**. `WonderBox-1.2.0.zip` is a **universal Apple Silicon / Intel** archive. Quit the old version, unzip and replace `WonderBox.app` in Applications, then reopen and enable the desired metrics as described above.

333 项自动测试无失败（5 项环境／权限相关测试跳过），7 项打包测试通过。另已验证原生菜单栏中的双项／单项显示、关闭窗口后的刷新、隐藏／恢复、彩色／单色图标，以及设置开关的实际交互。ZIP 解压后的版本、双架构、签名和中文资源均已校验；SHA-256 校验文件见附件 `SHA256SUMS`。

333 automated tests completed with zero failures and five environment/permission-related skips; all seven packaging tests passed. Native menu bar validation also covered both/single metrics, closed-window updates, hiding/restoring, both icon styles, and actual settings interactions. Extracted version metadata, architectures, signatures and Chinese resources were verified. The archive checksum is included in `SHA256SUMS`.

此版本沿用 **ad-hoc 临时签名，未公证**。原生界面验收在 macOS 26.5.2 上完成；Intel 真机及 macOS 14 的手动兼容性测试仍待补充。

This release remains **ad-hoc signed and not notarized**. Native UI validation was performed on macOS 26.5.2; manual compatibility checks on Intel hardware and macOS 14 remain outstanding.
